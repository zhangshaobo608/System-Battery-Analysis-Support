系统电池分析隐私政策

适用应用：系统电池分析-手机配置查询·电池健康分析管家
运营主体：Shenzhen Huoli Zhihui Technology Co., Ltd.
联系渠道：GitHub Issues（公开反馈请勿附真实日志、完整序列号或其他敏感信息）
生效日期：2026 年 10 月 30 日

系统电池分析帮助你了解设备与自己选择的系统日志。本政策说明当前版本如何在本机处理信息。应用完全免费，无广告、账号、会员或内购；不接入开发者业务服务器，不集成第三方广告、统计或分析 SDK，不进行跨应用追踪。

1. 我们在本机处理什么

  • 基础信息：设备机型标识、系统版本、屏幕规格、物理内存、当前电量、充电状态、系统热状态和存储空间等系统公开信息。机型标识用于表示设备型号，不是设备唯一标识。
  • 你选择的日志：仅在你通过系统文件选择器、文件打开或分享菜单主动选择后读取。按内容提取电池、配置或异常记录。处理时可能接触原文件中的信息，但应用只保存生成的结构化摘要，不将原始日志、完整堆栈或内核原文持久保存到本应用的数据目录。
  • 保存的报告：可能包括电池数值、来源机型与系统、日志及导入日期、原字段名与记录路径、配件型号/厂商/三字符前缀及参考依据、异常类型、相关应用或进程名、结构化证据，以及你确认的检查结果。原文件名和用于本机去重的文件内容指纹也可能保留。配置解析对部件序列字段只提取需要的三字符前缀，不保留完整部件序列号及其哈希。
  • 设备档案：你填写的档案名称、报告归属、机型和创建时间。档案名称是自由文本，请不要填写不必要的个人信息。
  • 充电记录：仅在你主动开始后记录前台电量、充电状态、时间和热状态等观察值；切到后台暂停采样。
  • 功能设置：监控卡片顺序、刷新间隔、提醒线、语音选项、档案偏好等保存在本机。监控只读取本应用进程与可用系统公开状态，不读取其他应用的内容。

以上处理不需要上传到开发者服务器。应用没有远程日志上传、账号同步或开发者云备份功能。iOS、本机文件服务或你另行选择的第三方服务如何处理数据，由其各自政策及你的设置决定。

2. 权限与临时内容

  • 相机：你主动开始相机或手电筒检查时按系统要求申请。相机只显示预览，不拍照、保存画面或上传。
  • 麦克风：你主动开始麦克风检查时申请，录制约三秒音频用于本机回放。退出检查会删除临时录音；若应用异常中断，系统临时目录中的残留可能在后续由系统清理。
  • 运动：用于你主动开始的可用传感器、气压与相对高度观察，不读取地理位置，不计算绝对海拔。
  • 蓝牙：仅在你主动开始蓝牙检查时申请，用于系统蓝牙可用状态，不扫描、连接、配对或收集附近设备。
  • 照片：点击保存报告卡时仅申请添加图片权限，不读取已有照片。保存后的图片由你在相册中管理。
  • 剪贴板：你点击“复制系统路径”时写入固定的系统操作路径；应用不读取剪贴板内容。

不申请定位、通讯录、广告追踪或远程推送权限。你可在系统设置中管理或撤回权限，拒绝不会阻止使用不依赖该权限的功能。分享/文件导入过程中由系统提供的临时文件仅用于当次本机解析，应用自行创建的文本临时副本在该解析流程结束时删除。

3. 悬浮教程、小组件与实时活动

画中画由你主动开启，显示本机生成的导入教程或监控最后读数。监控离开前台停止采样，悬浮画面保留“已暂停”和最后读数时间；不录制屏幕，不在后台采集日志或其他应用的数据。

主应用、分享扩展和小组件通过本应用专属的 App Group 共享容器交换数据。分享收件箱仅保存解析摘要；小组件使用电池健康、循环和更新时间等精简读数。实时活动显示你主动开始的充电记录状态及最后更新时间。锁屏、小组件或悬浮窗可能被旁人看到，可按系统提供的方式关闭或移除。

4. 保存、删除与系统备份

主动保存的报告、档案、充电记录和设置保留在本机，直到你删除对应记录、清除应用数据或删除应用，不设置自动过期时间。分享收件箱的待接收摘要在接收、删除或清理时移除，不会因为清除主报告记录而自动删除。

  • 在“记录”可删除单份报告；“设置 → 清除本地记录”只清除报告，保留档案名称、充电记录和分享收件箱。
  • 充电历史在充电页面独立删除或清理；分享摘要在“设置 → 整理分享收件箱”单独管理。
  • 当前版本没有单独删除档案名称的入口。若需清除包括档案和偏好在内的全部应用本地数据，可使用 iOS 的“删除 App”；“卸载 App”可能保留文稿与数据。系统对共享扩展、小组件和备份的处理以设备设置及实际提示为准。
  • 系统“分析数据”中的原件、你存入“文件”的原日志、已导出的备份、已分享的内容与已保存到相册的图片，不会随应用内删除操作自动删除，请到对应位置管理。

本机数据可能随 iOS 的设备备份保存，具体取决于你的备份设置；从备份恢复设备可能恢复相关数据。应用不控制 Apple 或其他服务保存的系统备份。

5. 你主动分享或导出时

只有你点击分享、保存或导出并选择接收方/位置后，内容才会交给系统分享菜单、文件服务、相册或你选择的应用。发送前请核对预览，不要在公开渠道分享未经检查的日志或备份。

文字摘要和报告图片不包含原始日志、完整部件序列号及原文件名；异常摘要可能包含相关应用/进程名称与结构化原因，周期报告可能包含你填写的档案名称。记录备份包含档案、分析摘要、来源文件名、字段/记录路径和本机去重指纹等信息，不能视为匿名文件。存储空间值仅供本机展示，不随报告分享或记录备份导出。充电记录独立备份。

6. 外部资料与网络

应用不内置通用网页浏览器。你主动点击配置参考来源时，会由系统打开外部资料网站；随后的网站请求、网络信息及其服务行为受该网站与浏览器政策约束。若你从 iCloud 或其他文件服务选择文件，系统/服务可能先下载原件；本应用不会将该下载行为描述为向开发者上传。

应用不销售、出租或向广告商提供你的信息。现有代码没有第三方 SDK、广告标识、设备唯一标识采集或开发者联网接口。Apple 及操作系统自身的诊断、备份和商店服务不由本应用控制。

本隐私政策和支持页面由 GitHub Pages 托管。你主动打开网页或前往 GitHub Issues 时，会向 GitHub 发起网络请求；其对请求信息的处理受 GitHub 隐私声明约束。我们未在这些页面加入统计、广告、追踪脚本或外部字体。使用 GitHub Issues 可能需要 GitHub 账号，公开提交的内容可能被他人看到；这与 App 本身无需账号、本机处理数据的方式不同。

7. 未成年人及政策更新

应用面向一般设备用户，不专门面向儿童，不设未成年人账号或社交发布功能。未成年人请在监护人指导下操作系统设置、导出文件或使用相机与麦克风检查。我们不通过应用收集用于建立个人画像的信息。

如功能或数据处理方式变化，我们会相应更新本政策。重大变化将在适当位置说明；新权限仍须经系统与用户授权。
